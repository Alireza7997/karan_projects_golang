# Karan Projects in Golang

Solutions to the practice problems from [karan/Projects](https://github.com/karan/Projects), implemented in **Go**.

Each problem lives in its own file, numbered and named after the exercise, so you can run any solution directly:

```bash
go run ./numbers/01.find_pi_to_the_nth.go
go run ./classic_algorithms/01.collatz_conjecture.go
```
